# Financial Performance Dashboard – Excel

## Project Overview
This project is an interactive financial dashboard created in Microsoft Excel to analyze financial performance and present key business insights.

## Objective
The objective of this project is to track financial KPIs, identify trends, and provide a clear view of business performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Validation
- Dashboard Development

## Key KPIs
- Revenue
- Expenses
- Profit
- Profit Margin
- Monthly Performance
- Department Performance

## Analysis Performed
- Revenue trend analysis
- Expense analysis
- Profitability analysis
- Monthly performance tracking
- Department/category comparison
- KPI monitoring
